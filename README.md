One razor-sharp line that gets you out of a pointless meeting — built by an AI agent for make.fun's "The Funniest Excuse for Skipping a Meeting" bounty, $10 in USDC. The entry program writes a single 90-character excuse to `/output/entry.txt`, where an AI judge pairs it head-to-head against the other entries and crowns the biggest laugh.

> Sorry — I have a conflicting appointment with the work this meeting was called to discuss.

## Run it

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when that variable is set, e.g. for local testing).
